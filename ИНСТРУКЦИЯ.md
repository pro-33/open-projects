# 🚀 Как разместить на GitHub Pages

## Быстрый старт (5 минут)

### Шаг 1: Создайте репозиторий
1. Откройте [github.com](https://github.com) и войдите в аккаунт
2. Нажмите зелёную кнопку **"New"**
3. Имя репозитория: `open-projects`
4. Выберите **Public** ✅
5. **НЕ** нажимайте "Add README"
6. Нажмите **"Create repository"**

### Шаг 2: Загрузите файлы
1. На странице репозитория нажмите **"uploading an existing file"** (синяя ссылка)
2. Откройте проводник Windows: `c:\Users\micha\projects\Vs`
3. Выделите ВСЕ файлы и папки:
   - `index.html`
   - `styles.css`
   - `README.md`
   - папка `open-store`
4. Перетащите в окно браузера
5. Дождитесь загрузки
6. В поле "Commit changes" введите: `Initial commit`
7. Нажмите зелёную кнопку **"Commit changes"**

### Шаг 3: Включите GitHub Pages
1. В репозитории перейдите на вкладку **Settings** (шестерёнка, вверху)
2. В левом меню найдите и нажмите **Pages**
3. В разделе **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: выберите **main** → **/ (root)**
4. Нажмите **Save**
5. Подождите 1-2 минуты

### Шаг 4: Готово! 🎉
Ваш сайт доступен по адресу:
```
https://ВАШ_НИК.github.io/open-projects/
```

Например: `https://misha.github.io/open-projects/`

## ❓ Частые проблемы

### "404 Page Not Found"
- Подождите 2-3 минуты после включения Pages
- Проверьте что `index.html` в корне репозитория

### Не работают стили/скрипты
- Проверьте что все файлы загружены
- Откройте Console (F12) и посмотрите ошибки

### Не сохраняется между страницами
- Это нормально для GitHub Pages
- localStorage работает в пределах одного домена

---

## 🔄 Как обновить сайт

1. Внесите изменения в файлы локально
2. На GitHub нажмите на файл
3. Нажмите карандаш (Edit)
4. Внесите изменения
5. Нажмите **"Commit changes"**
6. Сайт обновится через 1-2 минуты
