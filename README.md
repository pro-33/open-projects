# Open Projects 🚀

Экосистема открытых приложений с открытым исходным кодом.

## 📦 Проекты

### [Open Store](./open-store/)
Магазин open-source приложений с интеграцией GitHub.
- 48+ приложений
- Система рейтингов и отзывов
- Админ-панель с модерацией
- Интеграция с GitHub API

### [Open Messenger](./open-store/messenger/)
Современный веб-мессенджер.
- Мгновенные сообщения
- Отправка файлов до 2GB
- Блокировка пользователей
- Просмотр профилей
- Общий аккаунт с Open Store
